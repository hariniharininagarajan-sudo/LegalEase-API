# LegalEase

LegalEase is an AI-powered legal document drafting application.

It uses:

- Streamlit
- FastAPI
- Google Gemini
- Python
- python-docx
- FPDF

## Features

- Employment contracts
- NDA documents
- Lease agreements
- Freelance contracts
- Employment offer letters
- Service agreements
- Custom agreements
- AI document generation
- Editable preview
- TXT export
- DOCX export
- PDF export
- Logo branding
- FastAPI API
- Swagger documentation
- Automated tests
